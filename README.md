# AnaAfrikgo

Application de navigation et de transport multimodal.

## Stack technique

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Supabase
- Mapbox GL

## Démarrage

```bash
pnpm install
pnpm dev
```

## Structure du projet

```
src/
├── app/
│   ├── components/   # Composants de l'application
│   ├── contexts/     # Contextes React (auth, langue, pays...)
│   └── utils/        # Utilitaires (traductions, pays, langues)
├── styles/           # Styles globaux et thème
└── supabase/         # Fonctions serveur
```
